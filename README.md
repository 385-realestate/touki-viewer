# 登記簿ビューアー

不動産登記簿（土地・建物全部事項証明書）PDFを読み込み、
甲区・乙区・共同担保目録を解析するデスクトップアプリです。

## 動作環境

- Windows 10 / 11
- Python 3.10 以上

## セットアップ

```
pip install -r requirements.txt
```

## 起動方法

`start.bat` をダブルクリック、または：

```
python app.py
```

## フォルダ構成

```
touki_db/
├── app.py              # メインアプリ（GUI）
├── router.py           # PDF種別ルーター（土地/建物自動判別）
├── start.bat           # 起動バッチ
├── requirements.txt    # 依存パッケージ
├── README.md           # このファイル
├── scripts/
│   ├── touki_parser.py         # PDFパーサー本体
│   ├── db_writer.py            # SQLite DB書き込み
│   └── agents/
│       ├── base_agent.py       # 共通基底（持分累積計算）
│       ├── tochi_agent.py      # 土地エージェント
│       └── tatemono_agent.py   # 建物エージェント
├── database/           # SQLite DB（初回起動時に自動生成）
├── 登記簿公図データ/   # ここにPDFを配置（物件フォルダごとに整理）
└── output_csv/         # CSV出力先（自動生成）
```

## 使い方

### PDFの配置

```
登記簿公図データ/
└── 物件名フォルダ/
    └── 登記簿PDF.pdf
```

### PDF読み込み

1. アプリを起動
2. **「PDFを開く」** ボタンをクリック、またはPDFをウィンドウにドラッグ＆ドロップ
3. 土地・建物を自動判別して解析結果を表示

### 表示内容

#### 現在の所有者（確定 / 要精査）
- 持分合計が100%の場合：緑色ボーダー「現在の所有者（確定）」
- 持分合計が100%未満の場合：橙色ボーダー「現在の所有者（要精査）」＋不足分を表示

#### 甲区（所有権）履歴
- 全順位の登記を時系列カードで表示
- 現在：白背景・緑ボーダー
- 移転前：グレー背景

#### 持分タイムライン
- 甲区の順位ごとに所有者×持分をテーブル表示
- **分母を全行で統一**（LCM分母に揃える）→ 持分の増減が一目で追える
- 順位セル内に登記目的・受付日も表示
- 現在行の直前に緑の区切り線

#### 乙区（抵当権）
- 有効な抵当権：白背景・緑ボーダー
- 抹消済み：グレー背景
- 共同担保目録番号をアクセントカラーで強調（同番号の共担カードと対応）

#### 共同担保目録
- 乙区カード直下にインライン表示
- 有効なもの：白背景・緑ボーダー

### CSVエクスポート

解析後に **「CSV出力」** ボタンをクリックすると `output_csv/` フォルダに保存。

### 権利関係サマリー

乙区・共担の状態から自動判定：
- **権利クリア**：乙区なし または 抵当権すべて抹消済み
- **要確認**：抵当権が現存
- **要精査**：差押・競売・所有権移転仮登記あり

## 主な機能

| 機能 | 説明 |
|------|------|
| 持分累積計算 | 一部移転・付記更正が複数回続いても正確な現在持分を算出 |
| タイムライン | 全履歴の持分推移を統一分母の分数テーブルで可視化 |
| 乙区紐付け | 抵当権と共同担保目録を番号で自動マッチング |
| DB保存 | 解析結果をSQLiteに蓄積（物件比較・検索に活用） |
| CSV出力 | 甲区・乙区をCSVに一括エクスポート |

## 注意事項

- 登記簿PDFは法務省登記・供託オンライン申請システムからダウンロードしたものを使用
- PDFのフォーマットが大きく異なる場合、解析精度が低下することがある
- 個人情報を含むため取り扱いに注意
